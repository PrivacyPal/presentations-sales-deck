Every twin and action, anchored on-chain.

Tokenized, never exposed

Sensitive values become Privacy Twins. Only cryptographic hashes and content IDs are committed on-chain — never the underlying PII.

AI activity, audited on-chain

Each session is written as one immutable peaq transaction — user, machine identity, model and twin hashes. Tamper-proof.

DID-secured vault access

A peaq DID is each machine's cryptographic identity. An encrypted key vault and DID-gated endpoints control who can decode a twin.
